Folder AI Monitor (MVP)

==

Локальная система мониторинга папки с автоматическим анализом файлов через Gemini AI и отправкой результатов в Telegram.

Проект предназначен для персонального использования и экспериментальных R\&D-задач.

==



Возможности (MVP):

\- Отслеживание изменений в выбранной папке

\- Поддержка файлов:

&nbsp; - `.md`

&nbsp; - `.txt`

&nbsp; - `.pdf`

\- Анализ содержимого с помощью Gemini AI

\- Отправка структурированного результата в Telegram

\- Защита от повторной обработки (anti-duplicate)

\- Логирование работы и ошибок в файл



==

Требования:

\- Python 3.9+

\- Gemini API Key

\- Telegram Bot Token

\- Telegram `chat\_id`



==

Установка

1\. Клонирование репозитория



git clone https://github.com/USERNAME/folder-ai-monitor.git

cd folder-ai-monitor



2\. Виртуальное окружение(в командной строке)

python -m venv venv

venv\\Scripts\\activate



3\. Установка зависимостей

pip install -r requirements.txt



4\. Переменные окружения



Создайте файл .env в корне проекта:



GEMINI\_API\_KEY=your\_gemini\_api\_key

TELEGRAM\_BOT\_TOKEN=your\_bot\_token

TELEGRAM\_CHAT\_ID=your\_chat\_id



==

Конфигурация:



Настройки находятся в файле config.yaml:

-путь к отслеживаемой папке

-расширения файлов

-лимиты размера текста

-параметры Telegram

-логирование





==

Запуск

python monitor.py



==

После запуска система:

-начнёт наблюдение за папкой

-обработает новые и изменённые файлы

-отправит результат анализа в Telegram



==

Логирование

-Логи сохраняются в файл:

&nbsp;	logs/app.log
